# Project origin

Project started: 2026-09-21

Initial goal: evaluate whether Jev / TypeSafe AI can normalize and compare independently produced outputs from multiple divination systems for the same person and target period, using shared axes to study agreement and disagreement while preserving uncertainty and method-specific differences.

The repository begins with a minimal Jev System One connectivity example. Divination logic and Daily Run workflows are deliberately deferred until after the public, privacy-safe project baseline is established.

Public source and fictional fixtures belong in this repository. API credentials, real identity or birth data, personal readings, and private runtime outputs do not.
